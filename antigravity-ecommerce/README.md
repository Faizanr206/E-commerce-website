# Antigravity E-Commerce

A premium, space-themed MERN stack e-commerce application.

## Tech Stack
-   **Frontend**: React (Vite), Tailwind CSS v4, Framer Motion.
-   **Backend**: Node.js, Express, MongoDB.
-   **Currency**: PKR (₨).
-   **Testing**: Jest, SuperTest, Cypress.

## Setup Instructions
1.  **Backend**:
    -   `cd backend`
    -   `npm install`
    -   `npm start`
2.  **Frontend**:
    -   `cd frontend`
    -   `npm install`
    -   `npm run dev`

## Features
-   Antigravity Dark/Light Mode.
-   Verified Purchase Reviews.
-   Admin Dashboard with real-time KPIs.
-   Stripe Payment Integration (PKR).
